# Galèrapagos / Koh-Lanta

Jeu navigateur en un seul fichier (`index.html`), inspiré du jeu de société Galèrapagos, avec un mode Koh-Lanta (tribus, épreuves 3D, conseil, jury, finale).

- **Jouer** : ouvrir `index.html` dans un navigateur, ou activer GitHub Pages (Settings → Pages → Branch `main` / racine).
- **Solo, ordis ou plusieurs joueurs sur le même écran** : marche sans connexion.
- **En ligne** : bouton « 🌐 Jouer en ligne » → un joueur crée un salon (code à 4 lettres), les autres le rejoignent. Mise en relation via PeerJS (Internet requis).
